# بريد التحقق — ٢٦ أكتوبر ٢٠٢٦

## الإرسال المعتمد حاليًا

بناءً على اختيار المالك، يستمر إرسال البريد بواسطة Firebase دون مزود خارجي أو ترقية مدفوعة.

- حُفظت اللغة الافتراضية **Arabic** من Authentication → Templates.
- حُفظ اسم مرسل رسالة التحقق: **التحدي القرآني | QuranGames**.
- يحدد `src/cloud.js` اللغة `ar` عند إنشاء Auth، فتطلب رسائل التحقق واستعادة كلمة المرور العربية، حتى لو اختلفت لغة المتصفح.
- عنوان الإرسال التقني يبقى `noreply@qurangames-80d96.firebaseapp.com`. تغيير اسم المرسل لا يغير النطاق.
- نص التحقق الأصلي مقفول في لوحة Firebase، لذلك لا يمكن تطبيق الخلفيات والألوان عليه مباشرة. نجح حفظ اسم المرسل وحده بعد تعيين العربية، بينما أظهرت المحاولة الأولى لتغيير الاسم والعنوان معًا رسالة عدم إتاحة تحديث القالب.
- لم تُرسل رسالة اختبار إلى مستخدم فعلي خلال هذه المراجعة؛ تحقق الحفظ من لوحة Firebase، واختُبرت لغة طلبات العميل ببديل محلي لا يرسل بريدًا.

## القالب الملون الجاهز للمستقبل

`verification.html` قالب عربي RTL بألوان رِحلة: بترولي، زيتوني وذهبي، وجداول وتنسيقات داخلية متوافقة مع البريد. الخلفيات الصلبة تبقى عند عدم دعم التدرجات. `verification.txt` البديل النصي.

هذان الملفان **غير موصولين بالإرسال الحالي**. المتغيران `%DISPLAY_NAME%` و`%LINK%` أمثلة لاستبدال آمن على الخادم، وليسا روابط تفعيل حقيقية. عند الربط مستقبلًا، يجب ترميز الاسم وخصائص HTML، وإدراج رابط يولده Firebase Admin فقط، وعدم تسجيله أو إرجاعه للمتصفح. لا توجد صور خارجية أو بكسلات تتبع.

## تقييم بديل مجاني

يمكن تشغيل إرسال مخصص في وظائف Vercel القائمة مع Firebase Admin لتوليد رابط التحقق، دون استخدام Firebase Cloud Functions أو تغيير خطة Firebase:

| الخيار | الحد المجاني المعلن وقت المراجعة | متطلبات التشغيل |
| --- | --- | --- |
| Resend | ٣٠٠٠ رسالة شهريًا، بحد ١٠٠ يوميًا | نطاق إرسال موثّق ومفتاح خادم خاص؛ نطاق الاختبار غير مناسب لإرسال رسائل للمستخدمين |
| Brevo | ٣٠٠ رسالة يوميًا | تفعيل الإرسال وإثبات المرسل؛ توثيق نطاق تملكه أفضل للهوية وقابلية التسليم |

الخيار المقترح عند توفر نطاق: Resend لسهولة ربطه بالخادم الحالي. الحدود وشروط الخدمة قابلة للتغيير، ولا تعني هذه المقارنة ضمان التسليم أو مجانية التشغيل دون حدود. لا يوجد حاليًا نطاق يملكه المشروع أو حساب بريد جاهز بحسب المالك، لذلك لم يُفعّل أي مزود ولم تُشترَ خدمة.

قبل أي ربط مستقبلي: التحقق من ID token على الخادم، أخذ البريد من حساب المستخدم نفسه، منع الإرسال لبريد يختاره العميل، تحديد معدل الطلبات على الخادم والحصة اليومية، حفظ الأسرار في Vercel فقط دون بادئة `VITE_`، واستعمال قالب HTML وبديل نصي معًا. لا تكفي إضافة SMTP وحدها لإثبات إمكانية تخصيص متن التحقق المقفول.
